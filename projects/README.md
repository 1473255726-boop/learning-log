# 项目

当你能独立写出一个完整的小东西时，放到这里。一个项目一个文件夹，每个文件夹里必须有 README。

## 项目 README 写四段

1. **解决什么问题** —— 一句话
2. **怎么做的** —— 用了什么技术
3. **结果** —— 能跑、截图、数据
4. **踩过的坑** —— 这部分最值钱

## 建议的顺序

| 阶段 | 项目 |
|---|---|
| 学完基础语法 | 命令行计算器 / 猜数字游戏 |
| 学完文件操作 | 单词本 / 待办清单（存到本地文件） |
| 学完 OOP | 图书管理系统 |
| 学完 NumPy | 用 NumPy 手写一个神经网络 |
| 学完 PyTorch | 图像分类 / 文本分类 |
